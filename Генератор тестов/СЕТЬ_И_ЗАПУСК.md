# Запуск и подключение учеников

1. Запустите `start_server.bat` на ПК учителя. При первой настройке подтвердите запрос Windows на разрешение TCP-порта 8000 в локальной сети. При повторном запуске второй сервер не создаётся.
2. Кабинет учителя: <http://127.0.0.1:8000/teacher>. Во время работы сервер должен оставаться включённым.
3. В одной школьной сети ученики открывают ссылку из мониторинга работы. На этом ПК адрес Ethernet: <http://192.168.21.1:8000>. На другом ПК или после смены сети используйте адрес, показанный при запуске.
4. Адреса `192.168.*` недоступны через мобильный интернет. Для внешнего HTTPS-доступа подготовлен `ВКЛЮЧИТЬ_ИНТЕРНЕТ.bat`: он публикует ученический вход через Tailscale Funnel. Это отдельное явное действие публикации. Если Tailscale потребует включить Funnel в учётной записи, выполните его инструкции. На ученических устройствах Tailscale не нужен.
5. После включения внешнего доступа заново откройте мониторинг работы. Поле ссылки для учеников выберет внешний HTTPS-адрес. Ученикам отправляется полная ссылка `/exam/<идентификатор>`, а не адрес кабинета учителя. Ранее сохранённые HTML-страницы сохраняют старые адреса; для них создайте страницу заново или используйте прямую новую ссылку.

Внешний вход слушает только `127.0.0.1:8001` и пропускает страницы экзамена, ученические API и статические файлы. Кабинет учителя, API управления и документация через этот вход возвращают 404. Ответы и результаты сохраняются в прежней базе на ПК учителя. HTTPS-трафик учеников проходит через внешний сервис Tailscale Funnel; опубликованные учителем результаты доступны ученику по его токену попытки.

Внешний адрес сохраняется в `.runtime/public_url.txt`, исключённом из Git. Tailscale сохраняет Funnel в фоновом режиме. Отключение внешнего доступа: `tailscale funnel --https=443 off`; затем удалите `.runtime/public_url.txt`, чтобы кабинет больше не предлагал внешний адрес.

Если локальный адрес не открывается, проверьте, что устройство в школьной сети: гостевой Wi-Fi может быть изолирован от проводных ПК. Правило Windows разрешает только TCP 8000 из локальных подсетей, не отключает брандмауэр и не меняет категорию сети.

Проверка сервера: `python test_lan_server.py 192.168.21.1`. Скрипт поднимает сервер на временных портах с отдельной временной базой, проверяет 30 одновременных учеников, 120 сохранённых ответов, оценивание, повторную сдачу, запрет поздней перезаписи, большие ответы и ограничения внешнего входа.
