Переменные

Как программа запоминает данные и где она их хранит. Разберемся, как создавать «коробочки» для информации и правильно их подписывать.

Тема 1
Что такое переменная

Переменная — это именованная область памяти, в которой мы храним данные. Проще говоря, это подписанная коробочка, в которую можно положить число, текст или любой другой объект.

В Python переменные создаются в тот момент, когда вы впервые присваиваете им значение с помощью знака =.

Python 
# Создаем переменную name и кладем в нее строку
name = "Алексей"

# Создаем переменную age и кладем число
age = 25

print(name)
print(age)
# вывод ↓
Алексей
25

Тема 2
Правила именования переменных

Вы можете называть переменные как угодно, но есть несколько жестких правил, которые нельзя нарушать:

  • 1
    Символы: Имя может содержать только латинские буквы (a-z), цифры (0-9) и символ подчеркивания (_).
  • 2
    Цифры: Имя переменной не может начинаться с цифры.
  • 3
    Регистр: Python различает регистр. age, Age и AGE — это три разные переменные.
Правильно

user_name = "Alice"
score1 = 100
_top_secret = 42

Ошибка

1_place = "Gold"
user-name = "Bob"
my age = 20

Совет: Используйте понятные имена на английском. Вместо a = 5 лучше написать user_lives = 5. Это делает код читаемым.

Тема 3
Присваивание значений

В программировании знак = — это не математическое равно, а оператор присваивания.

Он работает так: сначала вычисляется значение справа от знака, а затем оно записывается в переменную слева.

Python 
x = 10
y = 5

# Сначала сложится 10 + 5, потом результат попадет в sum
total = x + y

print(total)  # Выведет 15

Тема 4
Изменение значения переменной

Значение переменной можно перезаписать. При этом старое значение полностью стирается, и переменная начинает ссылаться на новое.

Python 
score = 10
print(score)

score = 25  # Старое значение (10) удалено
print(score)

# Можно использовать текущее значение для расчета нового
score = score + 5
print(score)
# вывод ↓
10
25
30
