Переменные

Как программа запоминает данные и где она их хранит. Разберемся, как создавать «коробочки» для информации и правильно их подписывать.

Тема 1
Что такое переменная

Переменная — это именованная область памяти, в которой мы храним данные. Проще говоря, это подписанная коробочка, в которую можно положить число, текст или любой другой объект.

В Python переменные создаются в тот момент, когда вы впервые присваиваете им значение с помощью знака =.

Python 
# Создаем переменную name и кладем в нее строку
name = "Алексей"

# Создаем переменную age и кладем число
age = 25

print(name)
print(age)
# вывод ↓
Алексей
25

Тема 2
Правила именования переменных

Вы можете называть переменные как угодно, но есть несколько жестких правил, которые нельзя нарушать:

  • 1
    Символы: Имя может содержать только латинские буквы (a-z), цифры (0-9) и символ подчеркивания (_).
  • 2
    Цифры: Имя переменной не может начинаться с цифры.
  • 3
    Регистр: Python различает регистр. age, Age и AGE — это три разные переменные.
Правильно

user_name = "Alice"
score1 = 100
_top_secret = 42

Ошибка

1_place = "Gold"
user-name = "Bob"
my age = 20

Совет: Используйте понятные имена на английском. Вместо a = 5 лучше написать user_lives = 5. Это делает код читаемым.

Тема 3
Присваивание значений

В программировании знак = — это не математическое равно, а оператор присваивания.

Он работает так: сначала вычисляется значение справа от знака, а затем оно записывается в переменную слева.

Python 
x = 10
y = 5

# Сначала сложится 10 + 5, потом результат попадет в sum
total = x + y

print(total)  # Выведет 15

Тема 4
Изменение значения переменной

Значение переменной можно перезаписать. При этом старое значение полностью стирается, и переменная начинает ссылаться на новое.

Python 
score = 10
print(score)

score = 25  # Старое значение (10) удалено
print(score)

# Можно использовать текущее значение для расчета нового
score = score + 5
print(score)
# вывод ↓
10
25
30

Переменные
Задания: работа с данными

Переменные — это "коробки" для данных. Попрактикуйся правильно называть их и изменять их содержимое.

  • 1
    Первая переменная: Создай переменную city, запиши в неё название своего города и выведи её через print(city).
  • 2
    Стиль snake_case: Создай две переменные: user_name = "Алекс" и user_age = 15. Выведи их значения в одном print() через запятую.
  • 3
    Перезапись значения: Создай переменную status = "В пути" и выведи её. На следующей строке измени её значение на "На месте" и снова выведи.
  • 4
    Переменные в f-строке: Создай переменные film = "Интерстеллар" и rating = 9.5. Выведи с помощью f-строки: "Фильм: Интерстеллар, оценка: 9.5".
  • 5
    Вывод с разделителем sep: Создай три переменные day = 7, month = 11, year = 2025 и выведи их в одном print() с параметром sep=".".
  • 6
    Счёт с переменными: Создай переменные price = 250 и count = 4. Сохрани их произведение в переменную total и выведи её в f-строке f"Итого: {total}".
  • 7
    Увеличение счётчика: Создай переменную score = 10. Увеличь её значение на 15 (через score = score + 15) и выведи новое значение.
  • 8
    Множественное присваивание: Одной строкой создай три переменные a, b, c = 10, 20, 30. Выведи их через sep=" + " с окончанием end=" = ", а следующим print() выведи их сумму.
  • 9
    Обмен значениями: Создай переменные left = "чай" и right = "кофе". Поменяй их значения местами одной строкой left, right = right, left и выведи обе переменные в f-строке.
  • 10
    Карточка товара со скидкой: Создай переменные item_name = "Наушники", old_price = 8000, discount = 1500. Посчитай new_price = old_price - discount и выведи чек из двух строк (используя \n и f"...").
