Списки (Lists)

Представь, что тебе нужно записать имена 100 друзей. Вместо 100 переменных лучше использовать одну — список. Это как длинный стеллаж с пронумерованными полками.

Создание списка

Список создается с помощью квадратных скобок [ ]. Элементы перечисляются через запятую.

В списке могут лежать числа, строки и даже другие списки.

Python
numbers = [10, 20, 30, 40]
fruits = ["яблоко", "банан", "вишня"]
empty = [] # Пустой список
Доступ к элементам

У каждого элемента есть свой номер — индекс. В программировании отсчет всегда начинается с 0.

Чтобы достать элемент, напиши имя списка и индекс в квадратных скобках.

Python
names = ["Аня", "Боря", "Вера", "Глеб"]
print(names[0])    # Аня (первый элемент, индекс 0)
print(names[-1])   # Глеб (последний элемент, индекс -1)

# Срез списка: список[старт:стоп] (стоп не включается!)
numbers = [10, 20, 30, 40, 50]
print(numbers[1:4]) # [20, 30, 40] (элементы с индекса 1 по 3)
print(numbers[::-1]) # [50, 40, 30, 20, 10] (список наоборот)

Изменение элементов

Списки в Python — изменяемые. Можно легко заменить любое значение на новое, обратившись к нему по индексу.

cars = ["BMW", "Lada", "Tesla"]
cars[1] = "Audi" # Заменяем Lada на Audi
print(cars) # ['BMW', 'Audi', 'Tesla']
Длина списка len()

Функция len() (от англ. length — длина) показывает, сколько элементов в списке.

bag = ["ключи", "телефон", "кошелек"]
count = len(bag)
print("Предметов в сумке:", count) # Выведет 3
