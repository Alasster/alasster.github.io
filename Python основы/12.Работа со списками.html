Работа со списками

Списки редко остаются неизменными. Мы постоянно добавляем в них новые задачи, вычеркиваем выполненные и ищем среди них самые важные. Сегодня научимся управлять содержимым «полок» нашего стеллажа.

Добавление: append()

Метод append() добавляет новый элемент в самый конец списка.

Python
inventory = ["меч", "щит"]
inventory.append("зелье")
print(inventory) # ['меч', 'щит', 'зелье']
Удаление: remove и pop

Есть два основных способа убрать лишнее:

• remove(значение) — удаляет элемент по его имени. Если таких элементов несколько, удалится только первый.

• pop(индекс) — удаляет элемент по его номеру и «выплевывает» его (его можно сохранить в переменную).

tasks = ["учеба", "игры", "уборка"]
tasks.remove("уборка") # Удаляем по названию
deleted = tasks.pop(0) # Удаляем "учеба" по индексу 0
print(tasks) # Остались только ['игры']
Перебор списка циклом

С помощью цикла for можно легко перебрать все элементы списка по очереди. Это гораздо удобнее, чем обращаться к каждому индексу вручную.

playlist = ["Трек 1", "Трек 2", "Трек 3"]
for song in playlist:
    print("Играет:", song)
Максимум и минимум

Python умеет мгновенно находить самое большое и самое маленькое число в списке с помощью функций max() и min().

scores = [45, 99, 12, 87]
print(max(scores)) # 99
print(min(scores)) # 12

Полезные методы и функции для работы со списками:

• список.insert(индекс, значение) — вставляет элемент на нужную позицию (например, 0 — в начало).

• список.index(значение) — находит и возвращает индекс элемента.

• список.count(значение) — считает, сколько раз элемент встречается в списке.

• список.sort() — сортирует список по возрастанию или алфавиту (reverse=True — по убыванию).

• список.extend(другой_список) — добавляет все элементы другого списка в конец текущего.

• sum(список) — считает сумму всех чисел в списке.
