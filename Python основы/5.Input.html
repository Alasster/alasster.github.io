Ввод данных

Программа становится живой, когда она умеет слушать пользователя. Научимся получать информацию с клавиатуры и превращать её в нужный тип.

📥
Тема 1
Функция input()

Функция input() останавливает выполнение программы и ждет, пока пользователь что-нибудь введет и нажмет Enter.

Внутри скобок можно написать подсказку для пользователя — текст, который он увидит перед вводом.

Python 
input()  # Просто ждет ввода
input("Как тебя зовут? ") # Выводит подсказку

Тема 2
Сохранение в переменную

Чтобы использовать то, что ввел пользователь, результат функции input() нужно сохранить в переменную.

Важно: всё, что возвращает input(), всегда является строкой (str), даже если пользователь ввел число.

Python 
name = input("Введи имя: ")
print("Привет, " + name)
age = input("Сколько тебе лет? ")
print(type(age)) # Всегда выведет <class 'str'>
🎯 Какого типа будут данные в переменной x = input(), если пользователь ввел число 10?
⚙️
Тема 3
Преобразование типов

Чтобы работать с введенным значением как с числом (складывать, умножать), его нужно превратить из строки в число с помощью функций int() или float().

Python 
# Превращаем ввод в целое число
age = int(input("Ваш возраст: "))
print(age + 1) # Теперь математика работает!
# Превращаем ввод в дробное число
weight = float(input("Вес в кг: "))
print(weight * 2)

Ввод данных
Задания: диалог с программой

Функция input() всегда возвращает строку. Не забывай превращать её в числа, если планируешь что-то считать!

  • 1
    Простой ввод: Спроси у пользователя его город. Выведи фразу: "Ты живешь в городе: [название]".
  • 2
    Числовой ввод: Спроси у пользователя его возраст. Выведи, сколько ему будет через 5 лет (преврати ввод в int).
  • 3
    Эхо-программа: Попроси пользователя ввести любое слово и число n. Выведи это слово n раз в одну строку.
  • 4
    Дробные числа (float): Попроси ввести цену товара (например, 99.9). Выведи фразу: "Новая цена со скидкой: [цена - 10]".
  • 5
    Площадь прямоугольника: Запроси по очереди ширину и длину. Выведи площадь прямоугольника.
  • 6
    Верхний регистр: Попроси пользователя ввести свою фамилию. Выведи её, полностью переведя в заглавные буквы с помощью метода строки фамилия.upper() (он делает все буквы ЗАГЛАВНЫМИ).
  • 7
    Конвертер валют: Спроси сумму в долларах и текущий курс. Выведи результат в рублях.
  • 8
    Год рождения: Спроси текущий год и возраст пользователя. Выведи фразу: "Вы родились в [год] году".
  • 9
    Смена знака: Попроси ввести число. Умножь его на -1 и выведи результат с пояснением: "Противоположное число: ...".
  • 10
    Разделитель: Попроси пользователя ввести три любимых фрукта через пробел. Используй метод строка.split() (он разрезает текст по пробелам на отдельные слова) и выведи то, что получилось. (Это первый шаг к изучению списков!).
