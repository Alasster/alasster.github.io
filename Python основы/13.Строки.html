Работа со строками

Строки — это не просто текст, это цепочки символов. В Python мы можем измерять их длину, менять регистр и доставать отдельные буквы, как из коробок на складе.

Работа со строками

Строки можно складывать (склеивать) с помощью знака +. Это называется конкатенацией. Также строку можно "умножать" на число.

word1 = "Пи"
word2 = "тон"
print(word1 + word2) # Питон
print("Ха!" * 3)    # Ха!Ха!Ха!
Индексы строк

У каждого символа в строке есть свой номер — индекс. Счёт всегда начинается с 0.

Чтобы получить букву, используйте квадратные скобки: строка[индекс].

name = "Python"
print(name[0])    # P (самая первая буква)
print(name[-1])   # n (последняя буква)
print(name[0:3])  # Pyt (срез с 0 по 2 индекс)
print(name[::2])  # Pto (каждый второй символ)
print(name[::-1]) # nohtyP (строка задом наперёд!)
Методы upper() и lower()

Методы помогают быстро изменить вид текста:

• .upper() — делает все буквы ЗАГЛАВНЫМИ.

• .lower() — делает все буквы строчными (маленькими).

msg = "Привет"
print(msg.upper()) # ПРИВЕТ
print(msg.lower()) # привет
Длина строки: len()

Функция len() (от английского length — длина) считает количество всех символов в строке, включая пробелы и знаки препинания.

text = "Python 3"
длина = len(text)
print(длина) # 8
Что выведет len("Hi!")?
Метод split() — разбить строку

Метод .split() разрезает строку на части и возвращает список слов. По умолчанию разрезает по пробелам.

Можно указать любой разделитель в скобках: .split(",") — разрежет по запятой.

phrase = "яблоко банан апельсин"
fruits = phrase.split()
print(fruits)    # ['яблоко', 'банан', 'апельсин']
print(fruits[0]) # яблоко

data = "10,20,30"
nums = data.split(",")
print(nums) # ['10', '20', '30']
Метод join() — склеить список

Метод .join() — это противоположность split(). Он склеивает список строк в одну строку, вставляя между элементами нужный разделитель.

Синтаксис: "разделитель".join(список)

words = ["Python", "это", "круто"]
result = " ".join(words)
print(result) # Python это круто

parts = ["2025", "01", "15"]
date = "-".join(parts)
print(date)   # 2025-01-15
Что выведет "-".join(["a", "b", "c"])?
Поиск в строке: оператор in

Оператор in проверяет, есть ли одна строка внутри другой. Результат — True или False.

Также работает not in — проверяет, что подстрока отсутствует.

text = "Привет, мир!"

print("мир" in text)      # True
print("Python" in text)   # False
print("Python" not in text) # True

if "мир" in text:
    print("Слово найдено!")
Что выведет "кот" in "котлета"?
Метод replace() — замена

Метод .replace(что, на_что) заменяет все вхождения одной подстроки на другую и возвращает новую строку.

Важно: оригинальная строка не меняется — результат нужно сохранить в переменную.

text = "Я люблю кошек. Кошки — лучшие!"
new_text = text.replace("кошек", "собак")
print(new_text)
# Я люблю собак. Кошки — лучшие!

# Убрать все пробелы:
s = "п р и в е т"
print(s.replace(" ", "")) # привет

Ещё 6 супер-полезных методов строк для решения задач:

• s.strip() — убирает лишние пробелы по краям строки.

• s.title() — делает Первую Букву Каждого Слова Заглавной.

• s.swapcase() — меняет регистр наоборот (маленькие → БОЛЬШИЕ, БОЛЬШИЕ → маленькие).

• s.find("подстрока") — возвращает индекс первого вхождения (или -1, если не найдено).

• s.endswith(".pdf") — проверяет, заканчивается ли строка на указанный текст (True/False).

• s.isdigit() — возвращает True, если строка состоит только из цифр.
