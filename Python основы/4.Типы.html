4. Типы данных

В Python всё имеет свой тип. Разберемся, чем отличаются целые числа от дробных, как работать со строками и что такое логические значения.

Тема 1
Числовые типы (int, float)

В Python есть два основных типа для работы с числами:

• int (integer) — целые числа (без десятичной точки): 5, -10, 1000.

• float (floating point) — дробные числа (с точкой): 3.14, -0.5, 2.0.

Python 
apples = 10      # это int
price = 19.99    # это float

# Даже если дробная часть равна 0, число с точкой — это float
x = 5.0          # это float
Какого типа будет значение 15.0?
Тема 2
Строковый тип (str)

str (string) — это текст. Любые символы, заключенные в одинарные ' ' или двойные " " кавычки, становятся строкой.

Строки можно складывать (склеивать), но нельзя складывать строку с числом напрямую.

Python 
greet = "Привет"
name = 'Мир'

# Сложение строк (конкатенация)
message = greet + ", " + name + "!"
print(message)  # Привет, Мир!

# В кавычках число тоже становится строкой
x = "42"         # Это текст, а не число
Что выведет код: print("5" + "5")?
Тема 3
Логический тип (bool)

bool (boolean) — логический тип, который имеет всего два значения:

• True (Истина / Да / 1)

• False (Ложь / Нет / 0)

Этот тип незаменим, когда программе нужно принимать решения: включен ли свет? пройдена ли игра? равен ли пароль верному?

Python 
is_active = True
is_finished = False

# Логические значения часто получаются при сравнении
print(10 > 5)   # True
print(2 == 3)   # False
Как правильно пишутся логические значения в Python?
Тема 4
Определение типа: функция type()

Если вы не знаете, какой тип данных лежит в переменной, используйте встроенную функцию type(). Она покажет "класс" (тип) объекта.

Python 
print(type(42))        # <class 'int'>
print(type(3.14))      # <class 'float'>
print(type("Привет"))  # <class 'str'>
print(type(True))      # <class 'bool'>
Что вернет type("True")?

    Длина строки: Создай переменную phrase с любым текстом. Используй функцию len(phrase), чтобы узнать количество символов в ней, и выведи это число.
  • 5
    Сложение строк и чисел: Попробуй сложить "50" и 50. Получишь ошибку. Исправь её, превратив строку в число с помощью int().
  • 6
    Тип результата деления: Создай переменную res = 10 / 2. Выведи res и её тип. Почему даже при делении нацело получается float?
  • 7
    Многострочный текст: Создай переменную, используя тройные кавычки """ текст """, и запиши в неё небольшое стихотворение из 3-4 строк. Выведи её.
  • 8
    Логика из чисел: Проверь, что вернет функция bool() для чисел 1, 0 и -5. Выведи результаты.
  • 9
    Динамическая типизация: Создай переменную data = "123". Выведи её тип. Затем в эту же переменную запиши число 123 (без кавычек) и снова выведи тип.
  • 10
    Проверка типа: Используй функцию isinstance(v, int), чтобы проверить, является ли переменная v = 42 целым числом. Выведи результат (должно быть True).
