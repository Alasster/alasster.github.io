4. Типы данных

В Python всё имеет свой тип. Разберемся, чем отличаются целые числа от дробных, как работать со строками и что такое логические значения.

Тема 1
Числовые типы (int, float)

В Python есть два основных типа для работы с числами:

• int (integer) — целые числа (без десятичной точки): 5, -10, 1000.

• float (floating point) — дробные числа (с точкой): 3.14, -0.5, 2.0.

Python 
apples = 10      # это int
price = 19.99    # это float

# Даже если дробная часть равна 0, число с точкой — это float
x = 5.0          # это float
Какого типа будет значение 15.0?
Тема 2
Строковый тип (str)

str (string) — это текст. Любые символы, заключенные в одинарные ' ' или двойные " " кавычки, становятся строкой.

Строки можно складывать (склеивать), но нельзя складывать строку с числом напрямую.

Python 
greet = "Привет"
name = 'Мир'

# Сложение строк (конкатенация)
message = greet + ", " + name + "!"
print(message)  # Привет, Мир!

# В кавычках число тоже становится строкой
x = "42"         # Это текст, а не число
Что выведет код: print("5" + "5")?
Тема 3
Логический тип (bool)

bool (boolean) — логический тип, который имеет всего два значения:

• True (Истина / Да / 1)

• False (Ложь / Нет / 0)

Этот тип незаменим, когда программе нужно принимать решения: включен ли свет? пройдена ли игра? равен ли пароль верному?

Python 
is_active = True
is_finished = False

# Логические значения часто получаются при сравнении
print(10 > 5)   # True
print(2 == 3)   # False
Как правильно пишутся логические значения в Python?
Тема 4
Определение типа: функция type()

Если вы не знаете, какой тип данных лежит в переменной, используйте встроенную функцию type(). Она покажет "класс" (тип) объекта.

Python 
print(type(42))        # <class 'int'>
print(type(3.14))      # <class 'float'>
print(type("Привет"))  # <class 'str'>
print(type(True))      # <class 'bool'>
Что вернет type("True")?

Задания: изучаем типы

В Python всё является объектом определенного типа. Попробуй поработать с числами, строками и логикой!

  • 1
    Четыре базовых типа: Создай переменные a = 25, b = 4.5, c = "Python", d = True и выведи их значения в одном print() через sep=" | ".
  • 2
    Проверка через type(): Создай переменные x = 10 и y = 10.0. Выведи type(x) и type(y) и убедись, что их типы отличаются (int и float).
  • 3
    Динамическая типизация: Создай переменную data = "123" и выведи её тип. Затем перезапиши data = 123 и снова выведи type(data).
  • 4
    Превращение строки в число: Дана переменная text_num = "150". Преврати её в целое число с помощью int(text_num), прибавь 50 и выведи результат.
  • 5
    Отбрасывание дробной части: Создай переменную pi = 3.99. Сохрани результат int(pi) в переменную whole и выведи через f-строку: f"Было: {pi}, стало: {whole}".
  • 6
    Склейка строки и числа: Даны переменные title = "Уровень " и level = 5. Склей их с помощью +, предварительно превратив число в строку через str(level), и выведи результат.
  • 7
    Повторение строки: Создай переменную word = "Ура! " и переменную times = 3. Выведи результат умножения строки на число word * times.
  • 8
    Логический тип bool(): Проверь и выведи на экран в одной строке (через sep=", "), что возвращает функция bool() для значений 1, 0 и строки "Привет".
  • 9
    Сложение дробной строки и числа: Даны переменные price_str = "199.5" и delivery = "50". Переведи первую в float(), вторую в int(), посчитай сумму total и выведи её значение и type(total).
  • 10
    Паспорт ученика: Создай переменные student = "Алия", grade = "10", gpa = "4.85". Преобразуй grade в int, gpa в float, увеличь класс на 1 и выведи итоговую карточку через f-строку.
