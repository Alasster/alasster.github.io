6. Математические операции

Python — это мощный калькулятор. Он умеет не только складывать и вычитать, но и выполнять хитрые деления и возводить в огромные степени.

Тема 1
Основные операции (+ - * /)

Стандартные знаки математики работают привычно. Единственный нюанс: обычное деление (/) всегда возвращает дробное число, даже если результат целый.

Python 
print(10 + 5)  # 15
print(20 - 7)  # 13
print(4 * 3)   # 12
print(10 / 2)  # 5.0 (всегда float)
Какой результат выдаст код print(12 / 4)?
Тема 2
Целочисленное деление и остаток

Когда мы делим в столбик, у нас есть частное и остаток. В Python для этого есть свои символы:

• // — целочисленное деление (отбрасывает дробную часть).

• % — остаток от деления.

Python 
print(17 // 5) # 3 (сколько раз 5 влезло в 17)
print(17 % 5)  # 2 (что осталось после деления)
print(10 % 2)  # 0 (число четное, остатка нет)
Что выведет код print(10 // 3)?
Тема 3
Степень и приоритет

Возведение в степень в Python обозначается двумя звездочками **. Не путайте с одиночной звездочкой (умножением).

Приоритет операций такой же, как в школе: сначала скобки, потом степень, затем умножение/деление, и в конце сложение/вычитание.

Python 
print(2 ** 3)   # 8 (2 * 2 * 2)
print(5 ** 2)   # 25
print((2 + 2) * 2) # 8 (сначала скобки)
