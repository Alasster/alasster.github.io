Логические выражения

Программы постоянно принимают решения. Для этого они сравнивают данные и используют логику, чтобы понять: истинно утверждение или ложно.

Тема 1
Операторы сравнения (> < == !=)

Когда мы сравниваем два значения, Python возвращает специальный тип данных: bool (булевский). Он может принимать всего два значения: True (Истина) или False (Ложь).

Важно: для проверки равенства используются два знака равно = =, так как один знак = уже занят созданием переменных.

Python 
print(10 > 5)   # True
print(10 == 10) # True
print(7 != 7)   # False (не равно)
print(5 <= 3)   # False (меньше или равно)
Что выведет код print(15 != 10)?
Тема 2
Логические операторы (and, or, not)

Логические связки позволяют объединять несколько условий в одно сложное:

• and (И) — истинно, только если оба условия верны.

• or (ИЛИ) — истинно, если верен хотя бы один из вариантов.

• not (НЕ) — переворачивает результат (True превращает в False и наоборот).

Python 
print(10 > 5 and 3 < 1) # False (одно условие неверно)
print(10 > 5 or 3 < 1)  # True (одного верного достаточно)
print(not (10 == 10))   # False (инвертировали True)

Тема 3
Приоритет и проверка условий

У логики тоже есть порядок действий. Сначала выполняется сравнение, потом not, затем and, и в самом конце or.

В Python можно писать "красивые" двойные сравнения, например: 10 < x < 20.

Логика
Задания: сравнения и условия

Логика — это фундамент программирования. Научись комбинировать and, or и not, чтобы строить сложные проверки.

  • 1
    Проверка равенства: Создай переменные a = 15 и b = 15. Выведи результаты их сравнения a == b и a != b.
  • 2
    Сравнение разных типов: Выведи на экран результат сравнения числа 5 и строки "5" через 5 == "5". Объясни результат в комментарии.
  • 3
    Проверка возраста: Спроси возраст через age = int(input()). Сохрани результат проверки age >= 18 в переменную is_adult и выведи её в f-строке.
  • 4
    Отрицание not: Создай переменную is_raining = False. Выведи противоположное ей значение с помощью оператора not.
  • 5
    Проверка чётности через %: Спроси целое число n = int(input()). Выведи True, если оно чётное (n % 2 == 0), и False, если нечётное.
  • 6
    Одновременное условие (and): Пользователь вводит число x = int(input()). Выведи True, если число одновременно положительное (x > 0) и чётное (x % 2 == 0).
  • 7
    Хотя бы одно условие (or): Создай булевы переменные is_weekend = False и is_holiday = True. Напиши выражение с or, которое даёт True, если можно отдохнуть.
  • 8
    Попадание в диапазон: Пользователь вводит число n = int(input()). Проверь с помощью двойного неравенства 10 <= n <= 20, входит ли оно в отрезок от 10 до 20 включительно.
  • 9
    Двузначное и кратное 5: Пользователь вводит число n = int(input()). Выведи True, если число двузначное (10 <= n <= 99) и делится на 5 без остатка (n % 5 == 0).
  • 10
    Формула високосного года: Пользователь вводит год year = int(input()). Выведи True, если год високосный: делится на 4 и не делится на 100, либо делится на 400 ((year % 4 == 0 and year % 100 != 0) or year % 400 == 0).
