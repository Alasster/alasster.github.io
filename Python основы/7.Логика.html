Логические выражения

Программы постоянно принимают решения. Для этого они сравнивают данные и используют логику, чтобы понять: истинно утверждение или ложно.

Тема 1
Операторы сравнения (> < == !=)

Когда мы сравниваем два значения, Python возвращает специальный тип данных: bool (булевский). Он может принимать всего два значения: True (Истина) или False (Ложь).

Важно: для проверки равенства используются два знака равно = =, так как один знак = уже занят созданием переменных.

Python 
print(10 > 5)   # True
print(10 == 10) # True
print(7 != 7)   # False (не равно)
print(5 <= 3)   # False (меньше или равно)
Что выведет код print(15 != 10)?
Тема 2
Логические операторы (and, or, not)

Логические связки позволяют объединять несколько условий в одно сложное:

• and (И) — истинно, только если оба условия верны.

• or (ИЛИ) — истинно, если верен хотя бы один из вариантов.

• not (НЕ) — переворачивает результат (True превращает в False и наоборот).

Python 
print(10 > 5 and 3 < 1) # False (одно условие неверно)
print(10 > 5 or 3 < 1)  # True (одного верного достаточно)
print(not (10 == 10))   # False (инвертировали True)

Тема 3
Приоритет и проверка условий

У логики тоже есть порядок действий. Сначала выполняется сравнение, потом not, затем and, и в самом конце or.

В Python можно писать "красивые" двойные сравнения, например: 10 < x < 20.

Логика
Задания: сравнения и условия

Логика — это фундамент программирования. Научись комбинировать and, or и not, чтобы строить сложные проверки.

  • 1
    Проверка равенства: Создай две переменные с разными именами, но одинаковыми значениями. Выведи результат их сравнения через ==.
  • 2
    Возраст для входа: Попроси пользователя ввести возраст. Выведи True, если ему 18 лет или больше, и False, если меньше.
  • 3
    Сравнение типов: Сравни число 5 и строку "5" на равенство. Попробуй предсказать результат перед запуском.
  • 4
    Отрицание: Создай переменную is_raining = False. Используй оператор not, чтобы вывести противоположное значение.
  • 5
    Двойная проверка: Попроси пользователя ввести число. Проверь, является ли оно одновременно положительным и четным.
  • 6
    Выходной или отпуск: Создай две булевы переменные is_weekend и is_holiday. Напиши выражение, которое даст True, если хотя бы одно из условий верно.
  • 7
    Проверка наличия: Проверь, содержит ли введенная пользователем строка символ "@" и символ "." (точка). Выведи результат.
  • 8
    Сложный диапазон: Пользователь вводит число. Проверь, что оно не находится в диапазоне от 10 до 20 (включительно). Найди два способа сделать это.
  • 9
    Исключающее условие: Даны два значения. Напиши логическое выражение, которое вернет True только тогда, когда ровно одно из них истинно, а другое ложно.
  • 10
    Високосный год: Пользователь вводит год. Напиши сложное логическое выражение, которое определяет, является ли год високосным.
    (Подсказка: год високосный, если он делится на 4, но не делится на 100, либо если он делится на 400).
