Что такое программирование и Python

Программирование — это способ общаться с компьютером. Ты пишешь чёткие инструкции, а компьютер их выполняет.

Представь рецепт торта: ты пишешь шаги, а повар (компьютер) их делает. Язык программирования — это способ записать эти шаги так, чтобы компьютер понял.

Тема 3
Первая программа: print("Hello, world!")

Функция print() — главный инструмент для вывода текста на экран. Именно с неё начинается знакомство с любым языком программирования.

Python 
# Моя первая программа
print("Hello, World!")
print("Привет, Python!")
print(42)          # числа без кавычек
print(3.14)       # дробные числа тоже

Разбор по деталям:

• # — начинается комментарий, Python его игнорирует. Это пометки для себя.

• Текст в "кавычках" — это строка (слова, символы)

• Числа пишутся без кавычек: 42 это число, "42" — текст

• Каждый print() выводит новую строку

Тема 4
Ошибки в программе и как их читать

Ошибки — это нормально! Даже опытные программисты делают их каждый день. Python сообщает об ошибке точно и честно — главное, научиться читать сообщение.

Python — с ошибкой 
print("Hello World"   # забыли закрыть скобку
File "main.py", line 1
print("Hello World"
^
SyntaxError: '(' was never closed
Файл и номер строки — именно там ошибка
Строка с ошибкой — Python её показывает
Стрелка ^ указывает на проблемное место
SyntaxError — тип ошибки: нарушен синтаксис языка
SyntaxError

Нарушен синтаксис: забытая скобка, кавычка, двоеточие

NameError

Используешь переменную, которая не была создана

TypeError

Пытаешься сложить число и текст — несовместимые типы

IndentationError

Неверные отступы — в Python отступы обязательны

Главное правило: не бойся ошибок. Читай сообщение сверху вниз: тип ошибки → строка → описание. Если непонятно — скопируй текст ошибки и загугли!
