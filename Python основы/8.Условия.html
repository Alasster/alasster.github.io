Условные операторы

Программы становятся по-настоящему умными, когда начинают выбирать разные пути выполнения в зависимости от условий.

Тема 1
Конструкция if

Оператор if (если) позволяет выполнить блок кода, только если условие истинно (True).

Золотое правило: после условия обязательно ставится двоеточие :, а следующая строка должна иметь отступ в 4 пробела.

Python 
age = 18
if age >= 18:
    print("Доступ разрешен") # Сработает, так как 18 >= 18
Что случится, если забыть отступ после if?
Тема 2
Конструкция if - else

Когда нам нужно предусмотреть "план Б" на случай, если условие ложно (False), мы используем else (иначе).

Блок else не содержит условия — он просто срабатывает всегда, когда if не подошел.

Python 
temp = 15
if temp > 20:
    print("Надень футболку")
else:
    print("Возьми куртку") # Сработает это
Можно ли написать "else" без "if"?
Тема 3
Конструкция if - elif - else

Если вариантов больше двух, на помощь приходит elif (сокращение от else if). Программа проверяет условия по очереди, пока не найдет первое верное.

Python 
score = 85
if score >= 90:
    print("Отлично!")
elif score >= 70:
    print("Хорошо") # Сработает этот блок
else:
    print("Нужно подтянуть")
Сколько блоков elif может быть в одной конструкции if?
Тема 4
Вложенные условия

Внутри одного if может находиться другой if. Это называется вложенностью. Главное — следить за уровнями отступов.

is_rainy = True
have_umbrella = False

if is_rainy:
    if have_umbrella:
        print("Иду гулять")
    else:
        print("Жду дома") # Мы здесь

Задания: ветвление кода

Условный оператор позволяет программе "принимать решения". Напиши код, который будет вести себя по-разному в зависимости от ситуации.

  • 1
    Знак числа: Попроси пользователя ввести число. Если оно больше нуля — выведи "Положительное", если меньше — "Отрицательное", а если ноль — так и напиши.
  • 2
    Экзамен: Введи количество баллов (от 0 до 100). Если баллов 50 и больше — выведи "Зачет", иначе — "Незачет".
  • 3
    Термометр: Спроси температуру на улице. Если она ниже 10 градусов, выведи "Надень куртку!", а если 10 и выше — "Можно идти в кофте".
  • 4
    Доступ по возрасту: Если пользователю меньше 18 лет, выведи "Доступ запрещен". В противном случае напиши "Добро пожаловать".
  • 5
    Времена года: Пользователь вводит номер месяца (1–12). Выведи название времени года (Зима, Весна, Лето или Осень). Подумай, как объединить месяцы.
  • 6
    Мини-калькулятор: Попроси два числа и знак операции (+ или -). Программа должна выполнить соответствующее действие и вывести результат.
  • 7
    Делимость: Проверь, делится ли введенное число одновременно на 3 и на 5. Выведи ответ в свободной форме.
  • 8
    Максимум из трех: Попроси ввести три разных числа. Найди и выведи самое большое из них, используя только if, elif и else (без использования встроенной функции max).
  • 9
    Существование треугольника: Даны три отрезка a, b, c. Напиши программу, которая определит, можно ли из них составить треугольник.
    (Напомним: сумма любых двух сторон должна быть больше третьей).
  • 10
    Система скидок: Пользователь вводит сумму покупки. Если сумма больше 1000 — скидка 5%, если больше 5000 — скидка 10%, если больше 10000 — скидка 15%. Выведи итоговую цену.
    Будь внимателен к порядку проверок!
