Условные операторы

Программы становятся по-настоящему умными, когда начинают выбирать разные пути выполнения в зависимости от условий.

Тема 1
Конструкция if

Оператор if (если) позволяет выполнить блок кода, только если условие истинно (True).

Золотое правило: после условия обязательно ставится двоеточие :, а следующая строка должна иметь отступ в 4 пробела.

Python 
age = 18
if age >= 18:
    print("Доступ разрешен") # Сработает, так как 18 >= 18
Что случится, если забыть отступ после if?
Тема 2
Конструкция if - else

Когда нам нужно предусмотреть "план Б" на случай, если условие ложно (False), мы используем else (иначе).

Блок else не содержит условия — он просто срабатывает всегда, когда if не подошел.

Python 
temp = 15
if temp > 20:
    print("Надень футболку")
else:
    print("Возьми куртку") # Сработает это
Можно ли написать "else" без "if"?
Тема 3
Конструкция if - elif - else

Если вариантов больше двух, на помощь приходит elif (сокращение от else if). Программа проверяет условия по очереди, пока не найдет первое верное.

Python 
score = 85
if score >= 90:
    print("Отлично!")
elif score >= 70:
    print("Хорошо") # Сработает этот блок
else:
    print("Нужно подтянуть")
Сколько блоков elif может быть в одной конструкции if?
Тема 4
Вложенные условия

Внутри одного if может находиться другой if. Это называется вложенностью. Главное — следить за уровнями отступов.

is_rainy = True
have_umbrella = False

if is_rainy:
    if have_umbrella:
        print("Иду гулять")
    else:
        print("Жду дома") # Мы здесь
