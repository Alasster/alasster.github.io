Рекурсия в Python

Представь матрёшку, внутри которой лежит матрёшка поменьше, а в ней — ещё одна, пока ты не дойдёшь до самой маленькой фигурки. В программировании функция тоже может вызывать саму себя для более простой задачи — этот приём называется рекурсией.

Тема 1
Что такое рекурсия?

Рекурсия — это приём, когда функция вызывает саму себя внутри своего собственного кода.

Вместо того чтобы решать всю большую задачу сразу, рекурсивная функция делает один маленький шаг, а оставшуюся (уменьшенную!) задачу передаёт своей копии.

Аналогия: Матрёшка

Открываешь большую куклу → внутри кукла поменьше → открываешь дальше, пока не встретишь цельную малышку, которую уже не открыть.

Аналогия: Очередь

Чтобы узнать свой номер в очереди, спроси соседа спереди: «Какой ты по счёту?» — и прибавь 1. Первый в очереди сразу ответит: «Я — первый!».

Python — Первый пример рекурсии
def countdown(n):
    if n == 0:              # 1. Точка остановки (базовый случай)
        print("Старт!")
        return
    print(n)                 # Печатаем текущее число
    countdown(n - 1)         # 2. Функция вызывает саму себя с числом поменьше!

countdown(3)
# Вывод в консоли:
3
2
1
Старт!
Какая функция называется рекурсивной?
Тема 2
Два главных закона рекурсии

Чтобы рекурсия не превратилась в бесконечный круг, в каждой рекурсивной функции обязательно должны быть две части:

1. Базовый случай (стоп-кран)

Самый простой случай, когда ответ известен сразу и не нужно вызывать функцию снова. Записывается через if ...: return в самом начале функции.

2. Рекурсивный шаг

Вызов функции самой себя, но с изменённым аргументом, который приближает нас к базовому случаю (например, n - 1 или n // 10).

Что будет, если забыть базовый случай?

Функция будет вызывать себя сотни раз подряд, пока Python принудительно не остановит её с ошибкой RecursionError: maximum recursion depth exceeded (превышена максимальная глубина рекурсии — обычно около 1000 вызовов).

Python — Пример с ошибкой RecursionError
def broken(n):
    print(n)
    broken(n - 1)  # Ошибка! Нет условия остановки if n == 0

broken(3)
Что произойдёт, если в рекурсивной функции забыть базовый случай?
Тема 3
Возврат значения: сумма и факториал

Рекурсия особенно удобна, когда функция возвращает результат через return. Посмотрим, как посчитать сумму чисел от 1 до N и факториал числа.

Идея проста: сумма чисел от 1 до 4 — это число 4 плюс сумма чисел от 1 до 3!

Python — Сумма от 1 до N и Факториал
# 1) Сумма чисел от 1 до n:
def sum_to(n):
    if n == 1:              # База: сумма до 1 равна 1
        return 1
    return n + sum_to(n - 1) # Шаг: n + сумма остальных

print("Сумма от 1 до 5:", sum_to(5))  # 15


# 2) Факториал числа (1 * 2 * ... * n):
def factorial(n):
    if n <= 1:              # База: 1! = 1 (и 0! = 1)
        return 1
    return n * factorial(n - 1)

print("Факториал 4! =", factorial(4))  # 24

Как Python считает factorial(4) по шагам:

1. Погружение (прямой ход): factorial(4) ждёт ответа от 4 * factorial(3) → тот ждёт 3 * factorial(2) → тот ждёт 2 * factorial(1).

2. Дно рекурсии (база): factorial(1) сразу возвращает 1.

3. Подъём (обратный ход): 2 * 1 = 2 → 3 * 2 = 6 → 4 * 6 = 24. Готово!

Чему равен результат вызова sum_to(3), если sum_to(n) возвращает n + sum_to(n - 1), а при n == 1 возвращает 1?
Тема 4
Рекурсия с цифрами числа, строками и списками

В рекурсии можно использовать всё, что ты изучил в прошлых уроках:

• Деление // 10 и остаток % 10 (Урок 6) — чтобы отрезать по одной цифре от числа.

• Срезы списков и строк [1:] (Уроки 11 и 13) — чтобы на каждом шаге обрабатывать первый элемент [0], а в рекурсию передавать хвост [1:].

Python — Цифры числа и сумма списка
# Сумма цифр числа через % 10 и // 10:
def sum_digits(n):
    if n < 10:               # База: однозначное число
        return n
    return (n % 10) + sum_digits(n // 10)

print("Сумма цифр 483:", sum_digits(483))  # 3 + 8 + 4 = 15


# Сумма элементов списка через срез [1:]:
def recursive_list_sum(items):
    if len(items) == 0:      # База: пустой список
        return 0
    return items[0] + recursive_list_sum(items[1:])

print("Сумма списка:", recursive_list_sum([10, 20, 30]))  # 60
