Работа с файлами

Обычно данные в программе исчезают сразу после её закрытия. Чтобы сохранить результат своей работы — например, рекорд в игре или список дел — нам нужно научиться работать с файлами.

Открытие и закрытие

Чтобы начать работу, файл нужно открыть функцией open(). У неё есть два главных параметра: имя файла и режим (что мы собираемся делать).

• "w" (write) — для записи. Внимание: старое содержимое удалится!
• "r" (read) — только для чтения.

# Открываем файл для записи
f = open("notes.txt", "w")
# ... работаем с ним ...
f.close() # Обязательно закрываем!
Запись в файл: write()

После открытия файла в режиме "w", мы можем записывать в него текст с помощью метода .write().

f = open("test.txt", "w")
f.write("Привет, мир!")
f.close()
Чтение файла: read()

Чтобы прочитать данные, открываем файл в режиме "r" и используем метод .read(). Он вернет весь текст из файла как одну строку.

f = open("test.txt", "r")
content = f.read()
print(content)
f.close()

Дозапись ("a") и конструкция with open()

• Режим "a" (append) открывает файл для дозаписи в конец — старые данные не стираются!

• Метод f.readlines() читает все строки файла и возвращает их в виде списка строк.

• Конструкция with open(...) as f: — самый безопасный способ работы с файлами: Python сам закроет файл автоматически, даже если внутри произойдёт ошибка.

# Дописываем новую строку в конец файла
with open("notes.txt", "a") as f:
    f.write("Новая заметка\n")

# Читаем все строки файла в список
with open("notes.txt", "r") as f:
    lines = f.readlines()
    print("Всего строк:", len(lines))
