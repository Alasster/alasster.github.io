Создание функций

Представь, что функция — это «кнопка» или маленькая подпрограмма. Вместо того чтобы писать один и тот же код десять раз, мы сохраняем его в функцию и просто нажимаем на неё, когда нужно.

Что такое функция?

Функция — это именованный блок кода, который можно вызывать в любом месте программы. Это как рецепт: ты один раз записываешь, как готовить блины, а потом просто говоришь «готовь!», не перечитывая состав каждый раз.

Создание функции: def

Функция создается с помощью ключевого слова def (от англ. define — определить). После имени функции обязательно ставятся скобки и двоеточие.

def say_hello():
    print("Привет! Я функция.")

# Вызов функции:
say_hello()

Параметры функции

Функции могут принимать данные — параметры. Это переменные, которые работают только внутри функции и делают её гибкой.

def greet(name="Гость"):  # "Гость" — значение по умолчанию
    print("Привет,", name)

greet("Алекс") # Напечатает: Привет, Алекс
greet()        # Напечатает: Привет, Гость
Возврат значения: return

Функция может не просто печатать что-то, а возвращать результат своей работы обратно в основную программу с помощью return.

def double(number):
    return number * 2

result = double(5)
print(result) # Выведет 10

Задания: создаем свои команды

Функции позволяют не писать один и тот же код дважды. Сгруппируй логику в блоки и вызывай их тогда, когда нужно!

  • 1
    Персонализация: Напиши функцию greet(name), которая принимает имя и выводит: "Привет, [имя], добро пожаловать!".
  • 2
    Периметр: Создай функцию get_perimeter(a, b), которая рассчитывает и печатает периметр прямоугольника.
  • 3
    Значение по умолчанию: Напиши функцию say_hello(lang="RU"). Если аргумент "RU" — печатает "Привет", если "EN" — "Hello". Вызови её дважды: с аргументом и без.
  • 4
    Конвертер: Напиши функцию, которая принимает сумму в рублях и возвращает (через return) эту же сумму в долларах (курс задай самостоятельно).
  • 5
    Чет-Нечет: Создай функцию is_even(n), которая возвращает True, если число четное, и False в противном случае.
  • 6
    Минимум из списка: Напиши функцию, которая принимает список чисел и возвращает самое маленькое из них. Не используй встроенную функцию min().
  • 7
    Среднее арифметическое: Напиши функцию, которая принимает список оценок и возвращает средний балл.
  • 8
    Валидатор пароля: Создай функцию, которая принимает строку и возвращает True, если её длина больше 8 символов и в ней есть хотя бы одна цифра.
  • 9
    Фильтрация имен: Напиши функцию, которая принимает список имен и возвращает новый список, в котором остались только имена, начинающиеся на букву "A".
  • 10
    Мини-банк: Напиши функцию atm(balance, amount, action). Она должна принимать текущий баланс, сумму и действие ("снятие" или "пополнение"). Функция должна возвращать новый баланс или сообщение об ошибке, если денег для снятия недостаточно.
