Создание функций

Представь, что функция — это «кнопка» или маленькая подпрограмма. Вместо того чтобы писать один и тот же код десять раз, мы сохраняем его в функцию и просто нажимаем на неё, когда нужно.

Что такое функция?

Функция — это именованный блок кода, который можно вызывать в любом месте программы. Это как рецепт: ты один раз записываешь, как готовить блины, а потом просто говоришь «готовь!», не перечитывая состав каждый раз.

Создание функции: def

Функция создается с помощью ключевого слова def (от англ. define — определить). После имени функции обязательно ставятся скобки и двоеточие.

def say_hello():
    print("Привет! Я функция.")

# Вызов функции:
say_hello()

Параметры функции

Функции могут принимать данные — параметры. Это переменные, которые работают только внутри функции и делают её гибкой.

def greet(name="Гость"):  # "Гость" — значение по умолчанию
    print("Привет,", name)

greet("Алекс") # Напечатает: Привет, Алекс
greet()        # Напечатает: Привет, Гость
Возврат значения: return

Функция может не просто печатать что-то, а возвращать результат своей работы обратно в основную программу с помощью return.

def double(number):
    return number * 2

result = double(5)
print(result) # Выведет 10
