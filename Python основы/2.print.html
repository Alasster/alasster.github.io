Функция print()

Главный инструмент Python для вывода информации на экран. Разберём все возможности — от простого текста до красиво отформатированных строк.

Тема 1
Вывод текста на экран

print() — встроенная функция Python, которая выводит переданные ей данные в консоль. Это главный способ показать результат работы программы.

Каждый вызов print() по умолчанию заканчивается переносом строки — следующий вывод появится с новой строки.

Python 
# Вывод строк (текст — в кавычках)
print("Привет, мир!")
print('Одинарные кавычки тоже работают')

# Вывод чисел (без кавычек)
print(42)
print(3.14)

# Вывод результата вычисления
print(10 + 5)
print(100 * 2 - 7)
# вывод ↓
Привет, мир!
Одинарные кавычки тоже работают
42
3.14
15
193

Запомни разницу:

• "текст" или 'текст' — строка, набор символов

• 42 или 3.14 — числа, с ними можно считать

• "42" — это текст «сорок два», а не число!

Тема 2
Вывод нескольких значений

В print() можно передать сразу несколько значений через запятую. Python сам вставит между ними пробел и выведет всё в одну строку.

Python 
# Несколько аргументов через запятую
print("Имя:", "Алиса")
print("Возраст:", 17)
print("Сумма:", 3 + 4, "рублей")

# Разные типы данных вместе
print("Результат:", 10 * 5, "!")
# вывод ↓
Имя: Алиса
Возраст: 17
Сумма: 7 рублей
Результат: 50 !

Важно: Python автоматически ставит пробел между значениями. Это поведение можно изменить с помощью параметра sep — о нём в следующей теме.

Тема 3
Параметры sep и end

У функции print() есть два особых параметра, которые управляют форматом вывода:

• sep — что ставить между значениями (по умолчанию: пробел " ")

• end — что ставить в конце строки (по умолчанию: перенос "\n")

Параметр По умолчанию Что делает
sep " " (пробел) Разделитель между несколькими значениями
end "\n" (перенос) Символ в самом конце после всего вывода
Python — sep 
# sep — меняем разделитель между значениями
print("яблоко", "банан", "вишня")                 # по умолчанию
print("яблоко", "банан", "вишня", sep=", ")      # через запятую
print("яблоко", "банан", "вишня", sep=" | ")     # через черту
print("2024", "01", "15", sep="-")              # дата
print("а", "б", "в", sep="")                   # без разделителя
# вывод ↓
яблоко банан вишня
яблоко, банан, вишня
яблоко | банан | вишня
2024-01-15
абв
Python — end 
# end — меняем что идёт после вывода
print("Загрузка", end="... ")  # без переноса строки!
print("Готово!")

print("один", end=" ")
print("два", end=" ")
print("три")
# вывод ↓
Загрузка... Готово!
один два три

Символ \n — это специальный символ «перенос строки». Его можно использовать прямо в тексте:

print("строка1\nстрока2") — выведет две строки одним вызовом.

Тема 4
Форматированный вывод: f-строки

f-строки (f-strings) — самый удобный способ подставлять значения прямо в текст. Буква f перед кавычкой говорит Python: «внутри этой строки есть выражения в фигурных скобках {}».

Без f-строки

print("Привет, " + имя + "! Тебе " + str(возраст) + " лет.")

С f-строкой

print(f"Привет, {имя}! Тебе {возраст} лет.")

Python — f-строки 
имя = "Алиса"
возраст = 17
оценка = 4.75

# Подставляем переменные
print(f"Привет, {имя}!")
print(f"Тебе {возраст} лет.")

# Выражения прямо внутри {}
print(f"Через 5 лет тебе будет {возраст + 5} лет.")
print(f"Средняя оценка: {оценка:.1f}")   # 1 знак после запятой
print(f"2 + 2 = {2 + 2}")              # вычисление
# вывод ↓
Привет, Алиса!
Тебе 17 лет.
Через 5 лет тебе будет 22 лет.
Средняя оценка: 4.8
2 + 2 = 4
