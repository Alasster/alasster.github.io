Цикл while

Цикл while («пока») заставляет компьютер повторять действия до тех пор, пока выполняется определенное условие. Это как есть суп: пока тарелка не пуста, ты продолжаешь орудовать ложкой.

Принцип работы while

В отличие от for, который знает количество повторений заранее, цикл while работает, пока условие истинно (True).

Как только условие становится ложным (False), Python выходит из цикла и идет дальше.

Python
step = 1
while step <= 3:
    print("Повторение №", step)
    step = step + 1
Счётчики в цикле

Чтобы цикл не был бесконечным, внутри него обычно изменяют переменную, которая стоит в условии. Такая переменная называется счётчиком.

Python
popcorn = 5
while popcorn > 0:
    print("Ем попкорн...")
    popcorn = popcorn - 1  # Уменьшаем счётчик
print("Попкорн закончился!")
Что произойдет, если забыть строку "popcorn = popcorn - 1"?
Бесконечный цикл

Иногда нам нужно, чтобы программа работала постоянно (например, ожидала ввода пароля). Для этого используют while True.

Осторожно: если запустить такой цикл без выхода, вкладка браузера или программа может «зависнуть».

while True:
    print("Я работаю вечно!")
Break и Continue

Это специальные команды для управления циклом:

• break — немедленно «ломает» и завершает весь цикл.

• continue — перепрыгивает в начало цикла, пропуская оставшийся внизу код.

while True:
    answer = input("Выйти? (да/нет): ")
    if answer == "да":
        break  # Выход из бесконечного цикла
    print("Продолжаем...")
