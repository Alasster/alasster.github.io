ДИЗАЙН ЭЛЕМЕНТОВ · ALASSTER

Открыть: index.html в этой папке. Работает как статическая страница, в том числе при открытии файла с устройства.

78 примеров в 8 категориях. Коды постоянны: при добавлении примеров существующие коды не перенумеровывать.

Как ссылаться на дизайн:
«Оформи задания как CRD-01 · Стеклянная карточка».
«Используй TBL-01 · Таблица материалов, добавь колонку с датой».
Название и код копируются кнопкой внизу каждого образца. Нажатие на код открывает прямую ссылку на элемент.

Файлы:
index.html — оболочка каталога.
../стили/styles.css — общие переменные и исходные стили главной.
catalog.css — оформление каталога и компонентов ui-*.
components.js — реестр с названиями, описаниями и HTML каждого примера.
catalog.js — поиск, фильтрация и интерактивные демонстрации.
illustration.svg — локальная иллюстрация без внешней зависимости.
motion.css — отдельные анимации состояний, наведения, раскрытия и окон.
motion.js — сценарии появления всех 78 примеров, повтор и анимации обновлений.

Для новой страницы: подключить общие стили и перенести нужные ui-* правила и разметку компонента; для интерактивного элемента перенести соответствующий обработчик, адаптировав селекторы и идентификаторы. catalog.js управляет целым каталогом и не предназначен для подключения к произвольной странице без адаптации.

Форма ничего не отправляет. Социальные кнопки показывают пример действия, потому что адреса профилей не заданы. Тема и язык меняются только внутри своего образца. Видео и прикреплённые файлы открываются локально. Автопрокрутка запускается вручную. Google Fonts необязателен: есть системные запасные шрифты.

МОУШН-АНИМАЦИЯ
234 авторских сценария движения (по 3 уникальных варианта для каждого из 78 элементов) с тегами #Моушн-анимация, #Круто, #Шикаррно, #Чтоя. Для каждого типа элементов разработана своя кинематика: вееры и переклички для палитры, печатные шаги и маски для типографики, кристаллизация и контуры света для карточек, тактильные импульсы и пружины для кнопок, лазерные лучи и радары для контролов.

Под каждым образцом расположена интерактивная панель моушна:
— 3 кнопки выбора сценария (01, 02, 03) с авторскими названиями и мгновенным предпросмотром при клике.
— Динамический бейдж с тегом (#Моушн-анимация, #Круто, #Шикаррно, #Чтоя).
— Кнопка «Смотреть моушн» (↻), которая прокручивает превью в центр и запускает выбранный эффект.
— В спойлере «Как использовать» для каждого элемента приведён полный список всех 3 вариантов с их описанием и ориентирами для запросов к AI. Повтор не изменяет данные или состояние самого примера.

Над каталогом находится панель «Детали в движении»:
— «По настройкам устройства»: автоматические эффекты учитывают prefers-reduced-motion; кнопка «Смотреть моушн» по явному нажатию запускает полный эффект.
— «Полная анимация»: включает выразительные эффекты, в том числе если на устройстве движение ограничено.
— «Без анимации»: отключает эффекты и кнопки просмотра. Для возобновления выберите другой режим.
Выбор сохраняется локально в браузере; если хранилище недоступно, переключение работает в текущей вкладке.

Появление автоматически запускается один раз при входе карточки в область просмотра. Повтор — вручную. Декоративные циклы вне экрана приостанавливаются. При скрытии вкладки текущие эффекты останавливаются. Декоративные слои не перехватывают клики и удаляются после завершения. Исходный контент остаётся доступным без motion.js. Значения прогресса, числа, тексты, обработчики и данные демонстраций сохраняются.

Проверено: 123 браузерные проверки на ширине 1440 px и ещё 123 на ширине 390 px с системным уменьшением движения. В каждом запуске проверены все 78 кнопок просмотра, переключение режимов, поиск, фильтры, вкладки с клавиатурой, слайдер, формы, меню, FAQ, модальное окно, боковая панель, копирование и выбор локального файла. Ошибок JavaScript и горизонтального переполнения нет. Проверено удаление декоративных слоёв после проигрывания. Исходные catalog.js и components.js не изменялись.

Для переноса движения скопируйте нужные правила motion.css, адаптировав область .design-library и состояние data-motion. Сценарии motion.js относятся к каталогу; переносите только нужный сценарий с его селекторами. Для отключения дополнительного слоя удалите подключения motion.css и motion.js из index.html. В catalog.css системное уменьшение движения имеет исключение только для явно включённого data-motion="full".

Совместимость с телефоном: motion.css задаёт min-width: 0 колонкам каталога, чтобы горизонтальное меню не растягивало страницу за пределы экрана.
