03 / 05 · Протоколы

У интернета есть правила

Сетевой протокол — это набор правил, по которым устройства обмениваются данными. Он задаёт, как отправить сообщение и как его понять.

IP — адрес на посылке

Internet Protocol

IP отвечает за адресацию и передачу пакетов между сетями.

Пакет — небольшая порция данных с адресом получателя.

Куда отправить?

TCP — проверка доставки

Transmission Control Protocol

TCP обеспечивает надёжную передачу данных в правильном порядке.

Он контролирует получение и помогает повторить передачу потерянных данных.

Всё ли пришло?

FTP — файлы

File Transfer Protocol

FTP используют для обмена файлами с файловым сервером.

Обычный FTP не шифрует пароль и файлы.

HTTPS — защищённый веб

HTTP с защитой TLS

HTTPS защищает обмен между браузером и сайтом.

Например, при входе в электронный дневник.

TCP/IP — семейство протоколов: IP помогает доставить пакеты по адресу, TCP следит за порядком и получением.
