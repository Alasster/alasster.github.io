    03 / 06 · Устройство DNS

    DNS — телефонный справочник интернета

    DNS (Domain Name System) — распределённая система доменных имён. Она помогает найти IP-адрес сервера по его доменному имени.
    ☎
    В контактах: имя человека → номер. В DNS: имя сайта → IP-адрес.

    Проще запомнить «Алия», чем её номер телефона. Так же и с сайтом: человек вводит google.com, а DNS помогает компьютеру найти нужный IP. Это сравнение: DNS хранится на множестве серверов, а не в одной книге.

    Разбери имя справа налево

    Нажми на часть имени. Конечная точка — корень DNS; в обычной записи её чаще не показывают.

    А ты знал? У Казахстана есть не только .kz, но и домен .қаз — имя может быть не только латиницей.

    Какие бывают домены?

    Домен и полный адрес страницы — одно и то же?

    https://www.example.org/lesson

    https — схема защищённого обращения к сайту; www.example.org — доменное имя; /lesson — путь к ресурсу. Путь не является уровнем домена.

    www — обычная метка поддомена, а не обязательное начало каждого имени. example.org тоже может иметь адрес.

    05 / 06 · Протоколы

    У каждого протокола своя работа

    Протокол — согласованные правила обмена данными. Нажми на карточку, затем выбери протокол для каждой ситуации.

    Выбери протокол.
    Как они работают вместе?

    DNS помогает узнать адрес. HTTP задаёт обмен запросами и ответами веба; HTTPS защищает такой обмен с помощью TLS. IP обеспечивает адресацию и передачу пакетов между сетями.

    TCP помогает доставить данные полностью и в правильном порядке. FTP — протокол обмена файлами. У каждого протокола своя задача.

    Защита HTTPS относится к соединению. Она не гарантирует правдивость содержимого сайта.

    А ты знал? Буква S в HTTPS связана с защитой соединения. Но даже зашифрованный сайт может содержать неправду — информацию всё равно нужно проверять.
    06 / 06 · DNS-проект

    Мастерская DNS: запусти школьную олимпиаду

    Ты — DNS-администратор школьного сервера. Через час начинается онлайн-олимпиада, но зону DNS нужно заполнить. Сверь её со стойкой серверов, придумай новые сервисы и проверь популярные домены из командной строки.

    Индивидуальная работа · 10–15 минут · практика на ПК · 10 баллов

    1. Стойка серверов школы

    У каждого сервиса свой уникальный IP. При обновлении порядок меняется, но названия и адреса в стойке всегда связаны с DNS-зоной ниже.

    2. Зона DNS: наведи порядок

    Сопоставь имя сервиса с IP на стойке. Все поля пустые: самостоятельно внеси адреса и проверь себя. По 1 баллу за каждую верную запись.

    Доменное имяIP-адрес (заполни)
    Заполни все шесть записей и проверь зону. Максимум — 6 баллов.

    3. Дополни олимпиаду

    Придумай два новых онлайн-сервиса для олимпиады. Для каждого придумай понятное доменное имя внутри festival.mektep.kz, назначь новый уникальный IP из учебного диапазона 203.0.113.101–203.0.113.199 (не используй адреса со стойки) и объясни, почему это имя подходит сервису.

    4. Практикум в командной строке

    Нажми комбинацию WIN + R

    Открой CMD. Для каждого домена выполни обе команды:

    nslookup (подставь домен):

    Из nslookup запиши IP-адрес из ответа для домена. В графе ping отметь среднее время приема-передачи. Если ping не отвечает, это не обязательно ошибка DNS: сервер может блокировать ping.

    Популярный доменIP из nslookupРезультат ping
    google.com
    youtube.com
    instagram.com
    wikipedia.org
    kaspi.kz

    За таблицу IP-адресов после nslookup — 1 балл; за выполненные команды ping и записанные результаты (включая тайм-аут) — 1 балл.


    Оценивание — 10 баллов

    За зону: 0 из 6 баллов

    • Зона DNS: шесть верных соответствий — 6 баллов (по 1 за запись).
    • Мини-проект: для каждого сервиса — понятное доменное имя (0,5), уникальный IP (0,25) и объяснение выбора (0,25) — всего 2 балла.
    • Командная строка: IP из nslookup записаны для пяти доменов — 1 балл; выполнены ping-команды и записан результат для каждого — 1 балл.

    План работы на 10–15 минут

    1. Сопоставь стойку и пустую зону, заполни шесть записей — 5 минут.
    2. Придумай два сервиса олимпиады и оформи их DNS-записи — 4 минуты.
    3. Выполни nslookup и ping для пяти доменов, заполни таблицу — 5 минут.
