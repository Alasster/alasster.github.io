Снижение баллов

Что не засчитывается как исследование

Сплошной текст из одного сайта, общие фразы без примера, картинки без подписей, список ссылок без проверки, чтение презентации с экрана.

Правило авторства

Готовый материал — только основа

Если найденный текст вставлен без переработки, за этот фрагмент учитывается только факт наличия источника. Максимальные баллы даются за собственные схемы, сравнения, аргументы и выводы.

Формула хорошей работы: факт из источника → проверка → объяснение своими словами → анализ конкретного примера → собственный вывод. Копирование текста без переработки не даёт баллов за собственный анализ и авторскую работу.
