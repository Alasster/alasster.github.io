# Личный кабинет

Кабинет работает отдельно от корневого `index.html`. Генератор тестов перенесён внутрь папки кабинета и доступен в разделе «Тесты и задания»; исходная папка генератора оставлена нетронутым резервом.

В кабинете есть регистрация по имени, фамилии, email и паролю. Email используется как логин; подтверждение по SMS не требуется. Адрес `alasster@yandex.ru` получает роль супер-админа, а новые пользователи — роль `user`. Супер-админ может назначать роли `user`, `teacher`, `admin` и `superadmin` в кабинете.

В разделе «Уроки и классы» кабинет при открытии заново сканирует учебные папки сайта, группирует HTML-страницы по папкам и показывает тему из заголовка страницы. Добавленные страницы появляются в списке автоматически.

Генератор СОР/СОЧ встроен в раздел «Тесты и задания» и использует авторизацию кабинета. Его рабочая база находится в `generator/data/bagalau.sqlite3`, резервные копии — в `generator/backups/`. Исходная папка «Генератор тестов» сохраняется отдельно как нетронутый резерв.

## Запуск в PowerShell

Из этой папки задайте учётную запись через переменные окружения и запустите сервер:

```powershell
python -m pip install -r requirements.txt
$env:PERSONAL_CABINET_ADMIN_USERNAME = "your-login"
$env:PERSONAL_CABINET_ADMIN_PASSWORD = "your-password"
$env:PERSONAL_CABINET_ADMIN_NAME = "Ваше имя"
python server.py
```

После запуска откройте <http://127.0.0.1:8010/>.

Ученические страницы доступны через отдельный ограниченный gateway на порту 8001. Для локальной сети используйте `generator/start_server.bat`; он запускает кабинет и настраивает входящий доступ только для ученических страниц.

Пароль не записывается в исходники: при первом запуске он превращается в PBKDF2-хеш и сохраняется в `data/cabinet.sqlite3`. Сессия хранится на сервере, а браузеру выдаётся только HttpOnly-cookie. Для публикации по HTTPS установите `PERSONAL_CABINET_SECURE_COOKIE=1`.
