# Запуск и подключение учеников

1. Запустите `start_server.bat` на ПК учителя. При первой настройке подтвердите запрос Windows на разрешение TCP-порта 8001 в локальной сети. При повторном запуске второй сервер не создаётся.
2. Кабинет: <http://127.0.0.1:8010>. Во время работы сервер должен оставаться включённым.
3. В одной школьной сети ученики открывают ссылку из мониторинга работы. Адрес ученической страницы содержит путь `/generator/exam/<идентификатор>`. На другом ПК или после смены сети используйте адрес, показанный при запуске.
4. **Для телефона через обычный мобильный интернет или любой Wi-Fi запустите `ЗАПУСК_С_ТЕЛЕФОНА.bat`** на ПК учителя. Он сам запустит сервер в фоне, если тот ещё не работает, включит Tailscale Funnel и проверит внешнюю HTTPS-ссылку. Уже работающий сервер продолжит работу без перезапуска. `ВКЛЮЧИТЬ_ИНТЕРНЕТ.bat` делает то же самое. На ПК учителя нужен подключённый Tailscale; если он покажет ссылку включения Funnel, один раз откройте её и разрешите эту возможность в своей учётной записи. На телефоне не нужны Tailscale, школьный Wi-Fi и настройка IP. Адреса `192.168.*` через мобильный интернет не работают.
5. После включения внешнего доступа заново откройте мониторинг **уже существующей работы**. Поле ссылки для учеников выберет внешний HTTPS-адрес. Скопируйте и отправьте ученику полную ссылку `/generator/exam/<идентификатор>`. Учитель открывает вход в работу как обычно; ученик вводит имя и класс, выполняет задания и отправляет ответы в прежнюю базу на ПК учителя. Урок и работу пересоздавать не нужно. Ранее сохранённые HTML-страницы сохраняют старые адреса: для телефона используйте прямую HTTPS-ссылку из мониторинга.

После успешного запуска окно «ЗАПУСК_С_ТЕЛЕФОНА» можно закрыть; ПК учителя должен оставаться включённым, подключённым к интернету и не уходить в сон. При фоновом запуске журналы сервера находятся в `.runtime/phone-server.log` и `.runtime/phone-server-error.log`. Для остановки фонового сервера сначала дождитесь всех сдач, затем перезагрузите ПК; Tailscale Funnel выключается отдельно командой ниже.

Ученический вход слушает порт 8001 и пропускает страницы экзамена, ученические API и статические файлы. Кабинет учителя, API управления и документация через этот вход возвращают 404. Ответы и результаты сохраняются в прежней базе на ПК учителя. HTTPS-трафик учеников проходит через внешний сервис Tailscale Funnel; опубликованные учителем результаты доступны ученику по его токену попытки.

Внешний адрес сохраняется в `.runtime/public_url.txt`, исключённом из Git. Tailscale сохраняет Funnel в фоновом режиме. Отключение внешнего доступа: `tailscale funnel --https=443 off`; затем удалите `.runtime/public_url.txt`, чтобы кабинет больше не предлагал внешний адрес.

Если локальный адрес не открывается, проверьте, что устройство в школьной сети: гостевой Wi-Fi может быть изолирован от проводных ПК. Правило Windows разрешает только TCP 8001 из локальных подсетей, не отключает брандмауэр и не меняет категорию сети.

Проверка сервера: `python test_lan_server.py 192.168.21.1`. Скрипт поднимает сервер на временных портах с отдельной временной базой, проверяет 30 одновременных учеников, 120 сохранённых ответов, оценивание, повторную сдачу, запрет поздней перезаписи, большие ответы и ограничения внешнего входа.
